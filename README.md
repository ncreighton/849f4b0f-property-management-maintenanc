# Property Management Maintenance Request Bot

Telegram bot for property managers and landlords automating tenant maintenance requests. Tenants submit requests via bot with photos and priority level. Bot categorises the issue, assigns to contractor, sends confirmation to tenant, tracks status through to resolution, and logs all work orders with cost and completion date. Supports multi-property portfolios, monthly maintenance digest for landlords, contractor performance tracking, and automated rent reminder sequences. Works 24/7 without human intervention for routine requests.

## Setup
1. Set `TELEGRAM_BOT_TOKEN` in `.env`
2. `pip install -r requirements.txt`
3. `python main.py`
